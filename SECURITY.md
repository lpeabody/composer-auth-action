# Security policy

This action handles credentials. If you find a way for it to expose a
credential, write a file it should not, or otherwise behave unsafely, please
report it privately rather than opening a public issue.

## Reporting

Use GitHub's private vulnerability reporting for this repository:
<https://github.com/lpeabody/composer-auth-action/security/advisories/new>.

Include the action version or commit, a minimal workflow that reproduces the
problem, and what you observed. Do not include real credentials.

## Supported versions

The latest release of the current major (`v1`) receives fixes. Earlier majors
receive a backport only when a security issue warrants it.
